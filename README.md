# 🧮 Numi · Matemáticas a tu ritmo

Numi es una plataforma web de aprendizaje de matemáticas al estilo *Duolingo*: una ruta de lecciones gamificada donde practicas operaciones paso a paso, ganas XP, mantienes tu racha diaria y desbloqueas logros. Pensada para hacer que repasar matemáticas se sienta como un juego.

Proyecto desarrollado como parte del programa **Tecnolochicas**.

## 🚀 Demo en vivo

👉 https://tu-usuario.github.io/numi/

> Reemplaza `tu-usuario` por tu nombre de usuario de GitHub. El link se activa cuando habilitas GitHub Pages (Settings → Pages → Branch: `main`).

## ✨ Características

- **Ruta de aprendizaje gamificada:** un mapa tipo camino con paradas que se van desbloqueando una tras otra.
- **Unidad 1 · Operaciones básicas:** suma, resta, multiplicación, división y un repaso final que mezcla las cuatro.
- **Explicación antes de practicar:** cada lección abre con un tutorial breve, con ejemplos y trucos para resolver mentalmente.
- **Ejercicios variados:** preguntas de opción múltiple y de respuesta abierta, generadas de forma aleatoria cada vez.
- **Sistema de vidas (❤️), XP (⭐) y racha diaria (🔥):** igual que en las apps que ya conoces.
- **Logros desbloqueables:** primer paso, lección perfecta, racha de 3 días, y más.
- **Recompensa al terminar la unidad:** un cofre sorpresa con XP extra.
- **Progreso guardado:** tu avance se queda guardado en el navegador aunque cierres la página.
- **Diseño responsivo:** funciona en computadora y celular.

## 🛠️ Tecnologías

- **HTML5** — estructura de la aplicación.
- **CSS3** — estilos, animaciones y diseño responsivo (sin frameworks).
- **JavaScript (vanilla)** — toda la lógica: generación de ejercicios, navegación entre pantallas, sistema de XP/vidas/racha.
- **SVG** — ilustraciones del mapa (nubes, árboles, estrellas, el camino).
- **localStorage** — para guardar el progreso del usuario.
- **Google Fonts (Nunito)** — tipografía.

## 📂 Cómo usarlo

No necesita instalación. Solo:

1. Descarga o clona este repositorio.
2. Abre el archivo `index.html` en tu navegador.

¡Y listo! También puedes verlo directamente en el link de la demo.
